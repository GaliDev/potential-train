Task routing

Which agent should get the next task?

Pick a task type and route it. The router ranks every agent by measured competence on that task — then reliability, cost, and latency — and gates the pick. Ineligible agents (below the pass-rate floor) are shown but never chosen.

Platform & agent KPIs

Is the platform good — and is the fleet?

Two questions, kept separate. Platform KPIs ask whether the governance system itself is trustworthy and worth it. Agent KPIs are what the platform measures about the managed fleet.
